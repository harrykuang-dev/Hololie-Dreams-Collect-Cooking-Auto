# 版本記錄

## v1.1.0

- 新增DirectML推論，支援相容的AMD、Intel及NVIDIA顯示卡，相容NVIDIA顯示卡自動使用TensorRT。
- 單一完整版包含全部推論組件，不再依賴PyTorch，各後端共用同一批FP32模型檔案。
- 開發者模式永久保留每局分數、完成料理數、點擊、決策、等待原因及耗時。
- 診斷ZIP每個上限20 MB，較早截圖按容量淘汰，純文字超限時分卷保存。

## v1.0.1

- 點擊「開始」時嘗試切回遊戲，並還原最小化的遊戲視窗。
- 遊戲仍在最小化或尚未取得前景時繼續等待，取得前景後才開始操作。

## v1.0.0（已迭代）

- 提供標準ResNet18與進階ResNet101點位辨識模型。
- 所選點位分類器同時驗證主路徑與按需補充定位候選，採用所需食材的65%半徑門檻。
- 加入低紋理周邊移動檢查，抖盤需符合至少5秒實際輸入間隔與最新按鈕狀態。
- 模型載入、暖機與遊戲開始分開，載入期間可取消。
- 提供六語言介面與README，模型選擇及開發者模式採直接說明視窗。
- 點擊快捷鍵欄位後顯示輸入提示，保留Num Lock與Alt的獨立判斷。
- 開發者模式產生有容量上限的診斷ZIP，包含辨識、點擊時序、截圖及效能摘要。
- 統一輸入框高度與按鈕圓角底色，結束狀態使用料理配色。

## v0.2.0（已迭代）

- 提供Windows可攜前端、局數設定、自訂快捷鍵及選用錄影。
- 將模型與執行環境隨可攜套件提供。

## v0.1.0（已迭代）

- 建立食材分割、點位分類、三消規劃及畫面追蹤流程。
- 提供批次執行、畫面回放及模型權重。
